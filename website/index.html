Architecture

Multi-tenant from the ground up.

Every domain record is scoped to a school. Access control is three composable layers — authenticated, role, and fine-grained permission — and tenant isolation is covered by its own regression tests, not left to good intentions.

Payments are gateway-agnostic: Razorpay is live, Cashfree is wired behind the same interface. SaaS billing and parent fee-collection are kept as two separate systems, each with its own account and webhook secret.

BackendNode + Express + Mongoose, JWT auth with refresh, Zod validation, ~90 route groups
SecurityHelmet + CSP, rate limiting, optional 2FA, IP allow / deny lists, HMAC-verified webhooks, full audit log
